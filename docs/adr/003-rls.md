# ADR 003 — RLS em todas as tabelas

Status: aceita

## Contexto

Dados financeiros pessoais; a chave anon é pública.

## Decisão

RLS ativa com user_id = (select auth.uid()); views security_invoker; teste pgTAP de isolamento.

## Consequências

Toda tabela nova exige política e teste. O teste genérico falha se alguma tabela de `public` ficar sem RLS ou sem política; o isolamento entre usuários é conferido para carteiras, viagens, transferências e regras de categoria.
